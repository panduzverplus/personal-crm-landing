# Чигабугадага — лендинг

Одностраничный сайт личной CRM. Все кнопки ведут в приложение: https://app.chigabugadaga.ru

## Запуск на своём компьютере

```sh
pnpm install   # один раз, ставит зависимости
pnpm dev       # сайт с автообновлением: http://localhost:4321
pnpm build     # собрать готовый сайт в папку dist/
pnpm preview   # открыть собранный сайт из dist/
```

## Где что менять

- Адрес приложения, заголовок вкладки и описание для поисковиков — `src/consts.ts`
- Цвета, шрифты, размеры текста, скругления — `src/styles/tokens.css`
- Блоки страницы — `src/components/`, порядок блоков — `src/pages/index.astro`
- Шрифты подключены в `astro.config.mjs`: при сборке скачиваются с Google Fonts и раздаются с нашего сервера
- Макет — `design/`

## Выкатка

Новая версия выкатывается сама: push в ветку `main` — и через пару минут она на https://chigabugadaga.ru

Что при этом происходит (GitHub Actions, вкладка Actions в репозитории):

1. Собирает сайт: `pnpm build` → папка `dist/`
2. Копирует `dist/` на сервер в `/var/www/landing` (rsync; файлы, которых больше нет в сборке, удаляются)
3. Проверяет: главная отвечает 200 и показывает именно эту сборку

Зелёная галочка — выкатилось. Красный крестик — открыть запуск и посмотреть, на каком шаге сломалось. Если сломалась сборка, на сервере остаётся прежняя версия. Отката нет: исправляем и пушим снова.

Где что:

- `.github/workflows/deploy.yml` — шаги выкатки
- `deploy/ci-deploy.sh` — копирование на сервер и проверка главной
- `deploy/server/` — разовая подготовка сервера (`setup-landing.sh`) и настройка nginx для сайта
- На сервер файлы заливает отдельный пользователь `landing`: его ключ умеет только записывать в `/var/www/landing`, больше ничего
- Секретная часть ключа — только в секрете GitHub `DEPLOY_SSH_KEY`. Адрес сервера, пользователь и отпечаток сервера — в переменных репозитория `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_KNOWN_HOSTS`

Сменить ключ: создать новый, секретную часть положить в `DEPLOY_SSH_KEY`, публичную — на сервер рядом с копией `deploy/server` и выполнить там `sudo bash setup-landing.sh <новый-ключ>.pub`
