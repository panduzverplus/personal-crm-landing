# Чигабугадага — лендинг

Одностраничный сайт личной CRM. Все кнопки ведут в приложение: https://app.chigabugadaga.ru

## Запуск на своём компьютере

```sh
pnpm install   # один раз, ставит зависимости
pnpm dev       # сайт с автообновлением: http://localhost:4321
pnpm build     # собрать готовый сайт в папку dist/
pnpm preview   # открыть собранный сайт из dist/
```

## Где что менять

- Адрес приложения, заголовок вкладки и описание для поисковиков — `src/consts.ts`
- Цвета, шрифты, размеры текста, скругления — `src/styles/tokens.css`
- Блоки страницы — `src/components/`, порядок блоков — `src/pages/index.astro`
- Шрифты подключены в `astro.config.mjs`: при сборке скачиваются с Google Fonts и раздаются с нашего сервера
- Макет — `design/`
