# Handoff: лендинг «Чигабугадага»

## Overview
Одностраничный статичный лендинг сервиса личных контактов. Одно целевое действие — «Открыть приложение» (ссылка на веб-приложение; домен пока не определён → вынести URL в одну константу, напр. `APP_URL` в `src/consts.ts`, временно `#`).

Стек: **Astro + Tailwind CSS 4**, статическая сборка (`output: 'static'`), без клиентского JS.

## About the Design Files
`mobile.dc.html` и `desktop.dc.html` — **дизайн-референсы в HTML**, а не продакшен-код. Открываются в браузере напрямую (рядом лежит `support.js` — только рантайм превью, в проект его не переносить). Задача — воссоздать вёрстку в Astro-компонентах с Tailwind-классами. Все стили в референсах инлайновые — переносить их в утилиты Tailwind / токены `@theme`.

`landing-text.md` — исходный текст. Тексты использовать **дословно**.

## Fidelity
**High-fidelity.** Цвета, шрифты, размеры, отступы — финальные. Верстать pixel-perfect.

## Адаптив
- Мобильный макет — ширина 390px (`mobile.dc.html`, рамка 390px только для превью; на сайте — 100% ширины, горизонтальный padding 22px).
- Десктоп — `desktop.dc.html`, контейнер `max-width: 1440px; margin: 0 auto; padding-inline: 56px`.
- Переключение: мобильный < `md` (768px), десктоп ≥ `md`. Между 768 и ~1100px двухколоночные сетки десктопа складываются в одну (в референсе: `grid-template-columns: repeat(auto-fit, minmax(min(100%,460px),1fr))`; можно заменить на `lg:grid-cols-[1.25fr_1fr]`). Крупный кегль десктопа — через `clamp()` (см. ниже).
- Первый экран на мобильном в макете имеет высоту 844px; в реализации — `min-h-svh` с той же вертикальной композицией (карточка-превью растягивается `flex-1`, кнопка прижата к низу).

## Секции (по порядку)

### 01 Первый экран
- **Шапка**: flex, space-between; слева «Чигабугадага», справа «ЛИЧНЫЕ КОНТАКТЫ»; `padding-bottom` 14/16px, нижняя линия. На десктопе справа дополнительно маленькая кнопка «Открыть приложение» (h 40px, padding `0 8px 0 18px`, кружок-стрелка 26px).
- **Мобайл**: колонка `gap 18px`, `padding 18px 0`: «Ч» → H1 «Помните всех, кого знаете лично» → подзаголовок (сверху линия, `padding-top 14px`). Затем карточка-превью (`flex-1`), затем кнопка (`margin-top 16px`). Контейнер `padding 22px 22px 28px`.
- **Десктоп**: две колонки (1.25fr / 1fr, gap 64px, `align-items: end`, `padding-top 48px`, секция `min-height 860px`). Слева «Ч» + H1 (gap 32px). Справа (gap 20px): подзаголовок с верхней линией → карточка-превью → кнопка.
- **Карточка-превью** (декоративная иллюстрация продукта, не интерактивная; `aria-hidden="true"`): обводка 1px #000, radius 24/28px, padding 14/18px, gap 8/10px, шрифт Onest.
  1. Поле поиска: bg `#eef0ea`, radius 14px, h 46/50px, padding `0 14/16px`, иконка — кружок 12px с обводкой 2px `#1b2a22`, текст «петр иванов» 15/16px.
  2. Строка контакта: аватар 42/46px `#CA885B` с «ИП» (600, 14/15px); «Иванов Пётр» (600, 15/16px), «Откуда знакомы · заметка» (13/14px, `#060606`); нижняя линия `#eef0ea`.
  3. Скелетон-строка, opacity .45: аватар `#BF8156`, две полоски `#D3A484` (h 10px w 60% r 5px; h 8px w 40% r 4px).
- **Кнопка «Открыть приложение»**: `<a href={APP_URL}>`, bg ink, текст peach, h 64/72px, radius 999px, padding `0 22px` (мобайл) / `0 14px 0 28px` (десктоп), flex space-between; справа кружок 36/46px peach со стрелкой «→» цвета ink.

### 02 Как это работает
- Padding: мобайл `56px 22px 64px`, десктоп `96px 56px 120px`. Gap заголовка и списка 32/48px.
- Заголовок «Как это работает» с верхней линией (`padding-top 14/16px`).
- Шаги:
  1. **Откройте.** — Все ваши люди одним списком
  2. **Добавьте человека.** — Имя, откуда знакомы, телефон и почта
  3. **Поговорили?** — Найдите его по имени и допишите заметку
- Мобайл: список строк, grid `72px 1fr`, padding `20px 0`, линия сверху у каждой + снизу у последней.
- Десктоп: 3 колонки, линии сверху и снизу всего ряда, вертикальные разделители между колонками; в ячейке колонка с gap 56px (номер → заголовок/текст, gap 8px); padding `32px 32px 36px` (первая без левого, последняя без правого).

### 03 Удобно
- Тёмная секция на всю ширину: bg ink, текст peach. Padding как у 02.
- Заголовок «Удобно» с верхней линией peach.
- 3 карточки: обводка 1px peach, radius 24/28px, padding 18/28px. Мобайл — колонка gap 12px; десктоп — 3 колонки gap 16px, `min-height 220px`.
  1. «Поиск по запросу «петр иванов» найдёт «Иванов Пётр»» + ряд чипов (Onest 14/15px, gap 10px): чип «петр иванов» (bg peach, текст ink, padding `7px 12px`/`8px 14px`) → стрелка «→» (accent-on-dark) → чип «Иванов Пётр» (обводка peach). На десктопе чипы прижаты к низу карточки (`justify-content: space-between`).
  2. «У заметок есть дата, новые сверху»
  3. «В любом браузере те же контакты»

### 04 Финальный призыв + футер
- Мобайл: `padding 64px 22px 28px`, колонка gap 28px. Десктоп: `padding 120px 56px 32px`, две колонки как в первом экране (кнопка справа, выровнена по низу).

## Interactions & Behavior
- Все кнопки ведут на `APP_URL` (одна константа). Новая вкладка не нужна.
- Hover ссылок/кнопок: `opacity: .85`. Добавить видимый `focus-visible` outline (2px ink, offset 3px; на тёмной секции — peach).
- Анимаций нет. Состояний загрузки/ошибок нет.
